Préparation du déploiement sur SAP BTP (Cloud Foundry)

Déploiement
- Ajout du dossier deploy/ : manifest Cloud Foundry (backend Python
  + approuter Node.js), configuration de l'approuter (xs-app.json),
  sécurité XSUAA (xs-security.json)
- Script deploy.ps1 idempotent : build, création des services
  (xsuaa, user-provided AI Core et S/4HANA à partir du .env, via
  fichiers temporaires), cf push des deux applications
- Script cleanup.ps1 : suppression des seules ressources sap-ai-copilot-*
- Dépendances Python figées sur les versions testées en local
- SAPUI5 chargé depuis le CDN SAP dans la version déployée

Backend
- app/cloud_env.py : lecture des identifiants depuis les services
  liés (VCAP_SERVICES) sur BTP, sans effet en local

Frontend
- Adresse de l'API relative (api/) au lieu de 127.0.0.1:8000
- Proxy /api intégré à ui5 serve pour le développement local
  (streaming conservé)
- Jeton CSRF géré automatiquement pour l'approuter
- Détection de la session expirée
- Affichage de l'utilisateur SAP connecté dans la barre latérale

Divers
- deploy/build/ ignoré par Git
